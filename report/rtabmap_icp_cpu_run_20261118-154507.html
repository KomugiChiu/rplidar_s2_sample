跟隨期間 72.2%（p95 82.5%），比 15:31 的 66.5%（p95 71.0%）差，但優於調參前的 72.9% / 84.6%。 同一組 ICP 參數下，跟隨 p95 在 71~83% 之間跳動；59 s、13 筆取樣的 run 不足以定調，ICP 本身（update p95 90 ms、2.6 次丟幀/分）仍明顯優於調參前（129 ms、4.4 次/分）。
  • ICP 佔比 13.4%（15:31 為 11.9%），仍是最大單一節點；這次的差距主要來自 run 條件不同，而非參數。
  • 相機 11.3% + AI 6.6% 現在是第二大塊（17.9%），且與 ICP 調參無關。
  • ratio 中位 0.776（15:31 0.676、調參前 0.798）：本次移動少、靜止多，重疊自然較好。
  • 整段 max 95.1% 出現在 6.6 s（啟動尾段），10 s 之後最高只有 73.7%（t=19 s）——扣掉啟動，跟隨其實很穩。
  • 本次 59 s、移動 11.2 m；三次 run 的長度與行駛距離都不同，整體 mean 的差距不宜過度解讀，應看 ICP 的 update time / 丟幀率與 2 分鐘以上的 run。

7. 建議

  • 若要再降 CPU，下一個目標是相機（11.3%）：AI 關閉時只留 gyro/accel 可省掉大部分。
  • ICP 若在空曠場地 ratio 掉到 0.5 以下，把 Icp\RangeMax 改 10~12 再測。
  • 要驗證「跟隨時」的 odom 品質，建議推一段直線 + 轉彎，確認位移與實際距離相符；目前多為靜止/低速。
  • 要更乾淨的基準，可用 BAG=0 再跑一次，扣掉量測本身約 8%。
